# Online-Retail-Sales-Power-BI-Dashboard
📊 Online Retail Sales & Power BI Dashboard
 
End-to-end Business Intelligence Project — From Raw Data to Actionable Insights
 
 
 
📋 Project Overview
 
This project demonstrates a complete data analytics workflow: from raw transactional data → cleaning and transformation → data modelling → interactive visualisation. Built to showcase proficiency in Python, Power BI, and DAX.
 
 
 
📊 Dataset
 
Table
   
| Detail | Information |
|---|---|
| **Source** | Online Retail II — Public Transactional Dataset |
| **Records** | 800K+ transactions |
| **Time Period** | 2010 – 2011 |
| **Scope** | Multi-country retail sales data |
| **Key Fields** | Invoice, StockCode, Product Description, Quantity, Price, Customer ID, Country, Invoice Date |
 
 
 
🛠️ Tools & Skills Applied
 
- Python & Pandas — Data loading, cleaning, transformation, and export
​
- Power BI — Data modelling, relationships, dashboard design
​
- DAX — Custom date table, time intelligence, YoY comparison
​
- Excel — Data validation and supplementary analysis
 
 
 
🔄 Project Workflow
 
Phase 1 — Data Preparation
 
- Loaded raw dataset and assessed structure
​
- Handled missing values, duplicates, and data type inconsistencies
​
- Standardised date formats and created derived time columns
​
- Exported cleaned dataset for analysis
 
Phase 2 — Data Modelling
 
- Built custom DateTable using DAX for reliable time intelligence
​
- Established relationship between sales data and date table via  DateKey 
​
- Created measures: Total Sales, Total Quantity, YoY Growth %
 
Phase 3 — Dashboard & Visualisation
 
- Designed interactive sales overview dashboard
​
- Implemented dynamic slicers: Country, Year, Month
​
- Visualised sales trends and year-over-year performance
​
- Key metrics displayed: Total Sales, Total Quantity, Total Invoices
